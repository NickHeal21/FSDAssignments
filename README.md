# Front-End Development Assignments

This workspace contains six independent assignments:

1. **Assignment-1-Calculator** — browser-based calculator using JavaScript functions and a `switch` statement.
2. **Assignment-2-Todo-List** — interactive DOM to-do list with add, complete, and delete actions.
3. **Assignment-3-Form-Validation** — registration form with client-side field validation and error messages.
4. **Assignment-4-React-Profile-Card** — React profile card populated through props.
5. **Assignment-5-Controlled-React-Form** — controlled React form with a live preview.
6. **Assignment-6-React-Counter** — React counter with increment, decrement, and reset using `useState`.

Open `index.html` in a browser for assignments 1–3. For each React assignment, open its folder in a terminal, run `npm install`, then `npm run dev`.
